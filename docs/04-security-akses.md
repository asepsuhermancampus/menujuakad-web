## Kontrak modul authorization

Lokasi yang menjadi tanggung jawab worker:

| Berkas                                        | Tanggung jawab dan kontrak                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/server/authorization/session.ts`         | `server-only`; mengekspor tipe `VerifiedSession` dan `getVerifiedSession(): Promise<VerifiedSession \| null>`. Saat ini resolver harus selalu mengembalikan `null`. Tidak menerima input identitas dari UI dan tidak membaca cookie role/userId sebagai sesi.                                                                                   |
| `src/server/authorization/guards.ts`          | `server-only`; `requireCustomerSession(returnTo: string): Promise<VerifiedSession>` dan `requireSuperadminSession(returnTo: string): Promise<VerifiedSession>`. Keduanya memanggil resolver internal tanpa parameter sesi dari caller. Sesi tidak sah menyebabkan redirect aman ke login; customer hanya role CUSTOMER, admin hanya SUPERADMIN. |
| `src/server/authorization/redirect-policy.ts` | `server-only`; `buildSafeLoginRedirect(returnTo: string): string`. Hanya target lokal dengan root `/dashboard` atau `/admin`; hasil `/login?next=<target-encoded>` dan fallback `/login?next=%2Fdashboard`. Tidak mengambil host/origin dari request.                                                                                           |
| `src/server/authorization/*.test.ts`          | Pengujian behavior redirect dan penolakan akses. Jika Vitest perlu mematikan marker `server-only`, lakukan mock lokal per test, bukan konfigurasi runtime/build.                                                                                                                                                                                |

`VerifiedSession` hanya kontrak hasil verifikasi provider di masa depan: `userId` nonkosong, `role` CUSTOMER atau SUPERADMIN, dan `expiresAt` epoch milidetik. Guard memeriksa role secara case-sensitive, userId string yang tidak kosong setelah trim, expiry integer aman dan lebih besar dari `Date.now()`; epoch detik, expiry tepat saat ini, NaN/Infinity, pecahan atau bentuk sesi tidak lengkap ditolak. Exception resolver tetap dilempar agar kegagalan provider tidak melanjutkan render. Nilai ini merupakan konteks internal server; jangan mengirim seluruh objek ke Client Component, fixture, localStorage atau respons browser. TypeScript tidak membuktikan keaslian sesi. Resolver kelak wajib memverifikasi autentisitas token/session server, masa berlaku, pencabutan, status pengguna, serta mengambil role dari sumber server yang sah. Tidak menambahkan setter sesi, cookie simulasi, query `role`, atau mode bypass environment. Tidak mengklaim OAuth/login siap hanya karena tipe dan halaman auth tersedia.

Guard tidak menerima `session`, `userId`, role, headers atau object izin dari caller. Guard customer/admin adalah boundary peran, bukan bukti ownership resource. Query/action dan service berikutnya tetap harus memeriksa identitas serta membership OWNER/EDITOR/VIEWER pada setiap operasi. Akun SUPERADMIN tidak otomatis masuk ke konteks customer; perlu kebijakan impersonation terpisah yang diaudit apabila nanti diperlukan.

Redirect memakai allowlist root path, bukan pemeriksaan `startsWith('/dashboard')` saja: `/dashboardevil` dan `/adminevil` ditolak. Allowlist menerima maksimal 2.048 karakter, segment huruf ASCII/angka/underscore/hyphen, dan satu trailing slash opsional. Tolak URL absolut, URL `//host`, backslash, kontrol, whitespace, persen-encoding yang dapat menyembunyikan delimiter/traversal, dot segment, query redirect bersarang, hash, serta parameter role/userId. Untuk increment ini, target cukup path lokal bersih; query editor dapat dibuang oleh caller sebelum guard. Tidak meneruskan token/email/URL eksternal dalam `next`. Login consumer kelak tetap harus memvalidasi ulang `next` sebelum redirect setelah login.

## Integrasi route dan preview publik

Worker fullstack memasang `await requireCustomerSession('/dashboard')` di boundary server customer dan `await requireSuperadminSession('/admin')` di boundary server admin sebelum render atau pemuatan resource. Path lebih spesifik boleh dikirim jika lolos kebijakan redirect. Guard tidak dibungkus catch yang menelan exception redirect Next.js. Layout, menu tersembunyi, middleware/proxy, dan route group tidak menggantikan pemeriksaan setiap action/query terlindungi. Jika kode action/API belum diperlukan, jangan membuat endpoint dummy yang mengaku menyimpan data.

Route customer/admin sesungguhnya **tidak** menampilkan fake platform untuk pengunjung anonim. Resolver `null` berarti selalu deny/redirect, termasuk jika browser mengirim cookie `role=SUPERADMIN`, header `x-user-id`, parameter `?role=SUPERADMIN`, atau object sesi palsu. Keberadaan root guard tidak otomatis membuktikan seluruh route telah terpasang; verifikasi HTTP/RSC setelah integrasi milik fullstack.

`/preview-ui` adalah ruang PUBLIC terpisah dengan whitelist view yang eksplisit. Slug/view tak dikenal harus 404; jangan membangun dynamic import atau akses filesystem dari parameter browser. Fixture harus sintetis dan disanitasi: gunakan nama contoh, alamat `.example`, nomor/rekening placeholder, serta ID contoh yang tidak dipakai sebagai kunci database. Jangan memuat sesi, data Prisma, customer nyata, token tamu, payload webhook asli, nomor rekening nyata, atau credential provider. State pembayaran preview adalah tampilan contoh, bukan transaksi. Interaksi mengubah state lokal, tanpa server mutation, upload riil, Google OAuth, koneksi DB, pemanggilan Mayar, atau penerbitan undangan nyata.

Preview memakai metadata `robots: { index: false, follow: false }`, canonical tidak menunjuk resource customer, dan keterangan jelas bahwa data contoh. `noindex` mengatur crawler, bukan otorisasi. Worker fullstack menambahkan metadata dan route whitelist; tidak dilakukan worker Security di luar ownership ini. Halaman undangan contoh juga memakai fixture; token valid/publish/paid dari query browser tidak memberi akses resource nyata.

## Audit kode dan deployment baca-saja

Pada snapshot fondasi yang diperiksa, `src/server/env.ts`, `src/server/db/client.ts` dan query health memakai `server-only`. UI tidak mengimpor repository/provider; satu route health mengimpor query server sebagaimana mestinya. `DATABASE_URL` hanya dibaca modul server; konfigurasi browser yang terdeteksi adalah URL publik `NEXT_PUBLIC_APP_URL`. Tidak ditemukan pemanggilan provider, akses cookie/sesi, localStorage identitas, console log secret, atau innerHTML pada sumber fondasi yang diperiksa. Ini bukan scan menyeluruh kredensial seluruh riwayat maupun bukti semua perubahan paralel sudah diaudit.

Health hanya mengembalikan status umum; exception/URL koneksi tidak masuk respons. Root metadata saat audit sudah noindex. Header global menyediakan nosniff, strict-origin-when-cross-origin, X-Frame-Options DENY, dan pembatas kamera/mikrofon/geolokasi; CSP belum dipasang. CSP dapat disusun berdasarkan bundle/asset aktual dengan nonce atau hash setelah slicing; jangan menambahkan aturan ketat yang mematahkan hydration tanpa pengujian. HSTS menunggu HTTPS target terbukti stabil; tidak menambah preload/includeSubDomains tanpa inspeksi domain terkait.

Template systemd menjalankan user khusus `menujuakad`, bind localhost, environment di `/etc/menujuakad/`, `UMask=0027`, `NoNewPrivileges`, `PrivateTmp`, `ProtectHome`, `ProtectSystem=strict`, dan write access cache terlingkup rilis. Output/error menuju journal. Permission template lokal: Caddyfile/unit `664`, script `755`; file konfigurasi itu bukan rahasia. Mode/owner environment dan retensi journal pada VPS belum diperiksa. Ketika diterapkan, env rahasia minimal `0600` root, direktori release/config hanya writable pengelola, service tidak boleh menulis artifact aplikasi selain cache yang diperlukan. Jangan mencetak object session, header Authorization/Cookie, body webhook, query token reset/undangan, atau URL DB. Atur pembacaan journal dan retensi sesuai operator VPS.

Template Caddy hanya reverse proxy localhost dan canonical www; tidak menetapkan access log eksplisit. Konfigurasi global VPS dapat memengaruhi logging; belum diaudit. Jangan mencetak URI query sensitif di access log/error/observability. Audit/redaksi di proxy yang sesungguhnya sebelum auth/reset token aktif. Referrer policy existing tidak mencegah query bocor ke resource same-origin; URL token tidak boleh disalin ke link/analytics lain.

Pembungkus artifact menolak nama `.env`/`.env.*` kecuali `.env.example` yang kemudian dikecualikan, key SSH bernama standar, serta symlink di luar standalone. Pemeriksaan ini berbasis nama berkas, **bukan pemindai secret**: kunci `.pem`, token dalam `.json`, atau nilai inline JS masih perlu audit isi pada artifact final. SHA-256 bukan kontrol kerahasiaan. Worker tidak mengubah deployment atau menjalankan layanan. Catatan DevOps: target DNS berbeda dari workspace, HTTPS/SSH timeout; belum ada produksi terverifikasi.
