- Gunakan `node:crypto` bawaan untuk scrypt asinkron dan `timingSafeEqual`; kontrak final **N=32768, r=8, p=1, maxmem=64 MiB, salt16 byte acak, key64 byte**. Format tunggal `scrypt$32768$8$1$base64urlSalt$base64urlKey`. API menerima password **1–256 karakter, maksimal1024 byte**, tanpa trim; tolak hash/parameter/encoding abnormal dan input berlebih sebelum pekerjaan mahal. Akun tidak ditemukan tetap memakai hash dummy. Pengukuran biaya pada VPS tetap gate operasional.
- Sesi opaque memakai `randomBytes(32)` dengan token **base64url43 karakter** pada cookie; DB hanya menyimpan **SHA-256 hex64 karakter**. Tolak token malformed sebelum query; cookie tidak memuat JWT/role/identitas. Cookie `menujuakad_session`: `HttpOnly`, `Secure` pada produksi, `SameSite=Lax`, `Path=/`, tanpa `Domain`; expiry tujuh hari sesuai DB. Rotasi login/revokasi sesi browser lama mencegah fixation; expired/revoked/SUSPENDED menolak akses.
- Throttle persisten memakai reservasi atomik: budget email lima upaya/15 menit dan IP100/15 menit berdasarkan proxy tepercaya, dengan pemblokiran15 menit. Key email/IP dihash; jangan percaya `X-Forwarded-For` bebas. Status throttle sama dengan kredensial salah/SUSPENDED: **401**, pesan `Email atau kata sandi tidak sesuai.`, **tanpa429 atau Retry-After**. Reservasi email yang berhasil dilepas sesuai implementasi, budget IP tidak dihapus; paralel/restart/failure DB diuji lokal pada Security04.
- Login/logout dan semua mutasi cookie-auth memeriksa origin yang sesuai origin aplikasi, JSON dan ukuran input; SameSite bukan satu-satunya perlindungan CSRF. Tidak menerima origin arbitrer, URL eksternal/protocol-relative/backslash/control pada `next`, atau redirect peran customer menuju admin. Fallback customer `/dashboard`, superadmin `/admin`; kebijakan path existing tetap dipakai. Google/register/forgot/reset/verify tetap menerangkan layanan belum tersedia dan tidak menghasilkan sesi/email palsu; preview AUT tetap hanya interaksi lokal.
- Modul rahasia/repository berada di `src/server` dengan `server-only`; Server Component default, hook hanya interaksi UI. Guard layout tetap dipakai, tetapi **setiap** query/action/API protected memverifikasi sesi kembali. Role dan ownership tidak diterima dari body/hidden input, dan cache tidak boleh menggabungkan data antarpengguna. Kegagalan DB gagal tertutup; tidak beralih ke fixture sebagai identitas/data terlindungi. Resolver memanggil `await cookies()` sebelum pemeriksaan konfigurasi dan memakai `unstable_rethrow` untuk exception kontrol/rendering Next, sehingga build tanpa secret tidak membekukan redirect permanen. Regresi scoped tersedia; build kandidat final masih gate QA.
